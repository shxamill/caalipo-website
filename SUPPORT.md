# Support

## Getting help

- Open a Bug report for a reproducible layout or interaction problem.
- Open a Feature request for a focused storefront improvement.
- For local setup, include your Node.js version, operating system, command, and exact error.

Before opening an issue, check the README and existing issues. Include browser and viewport details for visual issues.

Do not post customer information, payment details, credentials, or unredacted logs. For security concerns, follow SECURITY.md. Support is provided on a best-effort basis.

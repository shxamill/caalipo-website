# Security Policy

## Reporting a vulnerability

Do not publish exploit details, credentials, payment data, personal information, or an unpatched vulnerability in a public issue or pull request.

Use the repository's **Security** tab and select **Report a vulnerability** to submit a private report when that feature is available. If private vulnerability reporting is unavailable, contact the maintainer privately through https://github.com/shxamill.

## Current application boundary

This repository is a static front-end prototype. Its cart and newsletter controls are not connected to a production payment or customer-data backend. Do not add real payment credentials or customer data to this repository.

Please allow the maintainer a reasonable opportunity to investigate before making a report public.
